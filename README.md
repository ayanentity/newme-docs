# newme-docs

GitHub Pages で公開しているプライバシーポリシー・利用規約と、友達の招待リンクの案内ページ。
独自ドメイン `newme.ayanentity.com`(`CNAME`)で配信している。旧 URL(ayanentity.github.io/newme-docs/...)は GitHub が自動でリダイレクトする。

- https://newme.ayanentity.com/privacy
- https://newme.ayanentity.com/terms
- https://newme.ayanentity.com/friend/ — 招待リンクの案内ページ(アプリがないときに開く)
- https://newme.ayanentity.com/.well-known/apple-app-site-association — ユニバーサルリンクの設定(`_config.yml` で出力に含めている)
